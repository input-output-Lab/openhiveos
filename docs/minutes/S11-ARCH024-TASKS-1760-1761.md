### Design

**IntegrationAdapter interface** defines four members:
- `provider: string` — Provider identifier ('clickup', 'jira', etc.)
- `enabled: boolean` — Env-driven opt-in flag
- `dispatch(row: SyncQueueRow): Promise<void>` — Outbound sync dispatcher
- `handleWebhook(payload: WebhookPayload): Promise<void>` — Inbound event handler

**Registry pattern** (ARCH-024 Amendment 1.2):
- All adapters registered in `allAdapters: IntegrationAdapter[]`
- `getEnabledAdapters()` returns only adapters where `enabled === true`
- Empty array if no providers enabled (system operates normally)
- `getAdapter(provider)` locates specific adapter by name
- `validateIntegrationRegistry()` validates all provider configs at boot

**ClickUp config validation:**
- `CLICKUP_ENABLED` — boolean gate (default: false)
- When enabled=true, requires: `CLICKUP_BOT_API_TOKEN`, `CLICKUP_BOT_USER_ID`, `CLICKUP_WEBHOOK_SECRET`
- Validation fails fast if any required var is missing (fail fast, don't continue degraded)

**JIRA config validation:**
- `JIRA_ENABLED` — boolean gate (default: false, planned for future sprint)
- Placeholder structure ready for future implementation
- Currently non-operational; stubs throw "not yet implemented"

### Schema: external_task_links (Migration 015)

**Purpose:** Bidirectional link table joining OpenHiveOS tasks to external provider counterparts.

**Columns:**
- `id BIGSERIAL PRIMARY KEY`
- `task_id BIGINT NOT NULL FK tasks(id) ON DELETE CASCADE`
- `provider TEXT NOT NULL` — Provider name (e.g., 'clickup', 'jira')
- `external_id TEXT NOT NULL` — Provider-specific task ID
- `external_url TEXT` — Direct link to task in provider
- `sync_state TEXT DEFAULT 'in_sync'` — Sync health (in_sync | drift | error)
- `last_synced_at TIMESTAMPTZ` — Last successful sync timestamp
- `created_at TIMESTAMPTZ DEFAULT NOW()`
- `updated_at TIMESTAMPTZ DEFAULT NOW()`

**Constraints:**
- PRIMARY KEY: `id`
- UNIQUE: `(task_id, provider)` — one external link per provider per task
- CHECK: `sync_state IN ('in_sync', 'drift', 'error')`
- CHECK: `provider ~ '^[a-z][a-z0-9]*$'` — lowercase alphanumeric only
- CHECK: `external_id ~ '^\S+$'` — non-empty, no leading/trailing whitespace

**Indexes:**
- `idx_external_task_links_task_id` — join path: find all external links for a task
- `idx_external_task_links_provider` — filter path: find all tasks linked to a provider
- `idx_external_task_links_sync_state` — error tracking: find all links in error state
- `idx_external_task_links_last_synced` — refresh tracking: find stale links

### Schema: sync_queue (Migration 016)

**Purpose:** Persistent async queue for outbound task sync operations (ARCH-024 Decision).

**Columns:**
- `id BIGSERIAL PRIMARY KEY`
- `task_id BIGINT NOT NULL FK tasks(id) ON DELETE CASCADE`
- `provider TEXT NOT NULL` — Provider name
- `payload JSONB NOT NULL` — Operation data (sensitive — never log)
- `status TEXT DEFAULT 'pending'` — Queue state (pending | dispatched | done | failed)
- `clickup_event_id TEXT` — Inbound deduplication key (Locksmith C3)
- `retry_count INT DEFAULT 0` — Failed attempt counter
- `created_at TIMESTAMPTZ DEFAULT NOW()`
- `updated_at TIMESTAMPTZ DEFAULT NOW()`

**Constraints:**
- PRIMARY KEY: `id`
- UNIQUE PARTIAL: `idx_sync_queue_clickup_event_id_unique` — unique on (clickup_event_id) WHERE clickup_event_id IS NOT NULL
- CHECK: `status IN ('pending', 'dispatched', 'done', 'failed')`
- CHECK: `provider ~ '^[a-z][a-z0-9]*$'` — lowercase alphanumeric only
- CHECK: `retry_count >= 0` — non-negative retry counter

**Indexes:**
- `idx_sync_queue_provider_status` PARTIAL — SyncWorker polling: find pending/dispatched rows for a provider
- `idx_sync_queue_task_id` — Task-specific queries: find all sync ops for a task
- `idx_sync_queue_clickup_event_id_unique` PARTIAL UNIQUE — Deduplication: prevent replay attacks (Locksmith C3)
